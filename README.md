# WHO — минималистичный магазин одежды

Чёрно-белый сайт-каталог на React + TypeScript (Vite). Без скруглений, строгая сетка, тонкие линии, адаптивная вёрстка.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Структура проекта

```
src/
  main.tsx                    — точка входа React
  App.tsx                     — шапка + переключение между главной и страницей товара
  types.ts                    — типы Product
  utils.ts                    — форматирование цены, сбор путей к картинкам
  hooks/useHashRoute.ts       — простой роутинг без библиотек (#/  и  #/product/<id>)
  data/products.ts            — 3 товара: худи + 2 футболки (артикул, цена, размеры, характеристики)
  styles/global.css           — все стили и дизайн-токены (цвета, шрифты, адаптив)
  components/
    Header.tsx                 — шапка, место под логотип слева
    HeroBanner.tsx              — баннер на всю ширину под главной картинкой
    ProductGrid.tsx             — сетка карточек на главной
    ProductCard.tsx             — одна карточка товара в каталоге
    ProductGallery.tsx          — большая фотография + миниатюры (для страницы товара)
  pages/
    HomePage.tsx                — главная: баннер + каталог
    ProductPage.tsx             — полноэкранная страница товара (галерея, размеры, кнопка, описание)
public/
  images/
    hero/banner.svg             — заглушка баннера на всю ширину
    logo/logo.svg                — заглушка логотипа
    hoodie-who/1.png...6.png     — фото худи
    tshirt-01/1.png...6.png      — фото футболки 1
    tshirt-02/1.png...6.png      — фото футболки 2
```

## Как открывается карточка товара

Клик по фото или кнопке «Подробнее» на главной странице переводит на **отдельную полноэкранную страницу** товара
(`#/product/<id>` в адресной строке — кнопка «назад» в браузере тоже работает), а не всплывающее окно.
Слева — крупное фото с листалкой и миниатюрами снизу, справа — название, артикул, цена, размеры, кнопка
«Добавить в корзину», описание и характеристики — как в примере, который вы прислали.

## Как поставить свой баннер

Замените файл `public/images/hero/banner.svg` на свою картинку (например `banner.jpg`), и поправьте путь
в `src/components/HeroBanner.tsx`, в атрибуте `src="/images/hero/banner.jpg"`.

## Как поставить свой логотип

Замените файл `public/images/logo/logo.svg` на свой (можно `.png`), и поправьте путь в
`src/components/Header.tsx`, в атрибуте `src="/images/logo/logo.png"`. Логотип стоит слева в шапке,
клик по нему возвращает на главную.

## Как добавить свои фото товара

Для каждого товара — своя папка в `public/images/`, например:

```
public/images/hoodie-who/1.png
public/images/hoodie-who/2.png
...
```

Файлы уже в формате `.png` — просто замените картинки-заглушки своими фото с теми же именами
(`1.png`, `2.png`, `3.png`...). Ничего в коде менять не нужно, если только не хотите изменить
количество фото — тогда поправьте `imageCount` в `src/data/products.ts`.

## Как отредактировать текст, цены, размеры

Всё лежит в одном месте — `src/data/products.ts`:

```ts
{
  id: "hoodie-who",
  imageFolder: "hoodie-who",
  imageCount: 6,
  name: "Худи WHO",
  sku: "WHO-HD-001",          // артикул
  category: "Худи",
  description: "Моя боль постоянна и остра",   // поэтичная строка на карточке и странице товара
  price: 3999,
  oldPrice: 5499,              // необязательно — если убрать, старая цена не покажется
  sizes: ["S", "M", "L", "XL", "2XL"],
  details: [                   // список характеристик на странице товара
    "DTF-печать: яркий и стойкий принт",
    "Oversize-крой: свободно, удобно, стильно",
  ],
}
```

Текст про подарок в посылке — константа `BONUS_NOTE` в конце того же файла, меняется в одном месте сразу
для всех товаров.

## Кнопка «Купить»

На странице товара — одна кнопка «Купить», которая открывает Telegram-чат с аккаунтом, указанным в
константе `TELEGRAM_USERNAME` (в конце `src/data/products.ts`, сейчас `"who1349"`), и сразу подставляет
в поле ввода текст с названием товара, артикулом, выбранным размером и ценой. Чтобы сменить аккаунт —
поменяйте одну строку в этой константе.

(В сетке каталога на главной у карточек по-прежнему две кнопки — «Подробнее» и «Добавить в корзину»;
если их тоже нужно убрать, скажите — уберу.)

## Дизайн

- Фон: почти чёрный `#050505`, карточки и страница товара `#0a0a0a`.
- Границы — только тонкие линии `1px`, без скруглений (`border-radius: 0` жёстко задан глобально).
- Шрифты: Archivo (интерфейс, заголовки) + PT Serif Italic (эмоциональные описания товаров).
- Единственный цветовой акцент — приглушённый красный, только на зачёркнутой старой цене.
- Адаптив: сетка каталога 3 → 2 → 1 колонка, страница товара — 2 колонки → 1 колонка на мобильных,
  шапка и баннер уменьшаются по высоте на маленьких экранах.
